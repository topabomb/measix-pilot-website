# 隐私可控的纯本地客户端

> 你的数据，你做主。Measix Pilot 是一款**隐私优先**的 Android AI 客户端——所有密钥、对话记录和配置都存在你的手机上，不上传任何云端服务器。

## 四大隐私承诺

### 1. 数据不出设备

- **密钥本地存储**：你填写的 API Key 仅保存在手机应用私有空间，不经过任何中间服务器
- **对话记录本地保存**：所有聊天记录存在手机本地，不上传云端
- **助手配置本地管理**：助手人设、工具配置全在设备上
- **工作区文件本地存储**：AI 的工作文件都在应用私有目录

### 2. 无账号、无注册

- 安装即用，不需要邮箱、手机号或任何身份信息
- 不存在登录入口，没有 session token
- 不收集用户行为数据，不构建用户画像

### 3. 无遥测、无上报

- **无崩溃上报**：不自动发送崩溃日志到任何服务器
- **无使用统计**：不统计功能使用频率、不上报设备信息
- **无广告 SDK**：不含任何广告或分析追踪组件

### 4. 网络请求透明

- **直连 AI 服务商**：网络请求直接发往你配置的 AI 服务商（如 `api.openai.com`），不经过代理
- **密钥遮罩显示**：MCP 服务器的请求头密钥默认按密码方式遮罩，需手动点击才临时显示
- **工具调用审批**：所有工具调用支持人工审批，你决定哪些工具可以自动执行

## 安全机制

### 密钥保护

- 密钥存储在 Android 应用私有空间，仅应用自身可访问
- 设置页的敏感配置项以密文形式展示，防止截屏泄露
- MCP 服务器配置中的请求头值默认遮罩

### 工具执行审批

- **人工审批**：工具调用前可以要求你确认
- **审批策略**：可设置工具为「始终允许」「每次询问」或「禁止使用」
- **安全降级**：工具超时不中断对话，自动转为文本提示

### 工作区隔离

- 工作区是一个隔离的 Linux 环境，不会影响你的 Android 系统
- 你上传的文件对 AI 只读，AI 需修改时必须先复制一份
- 系统关键目录不允许 AI 直接访问

## 备份与恢复

- **本地备份**：支持导出/导入备份文件，完全离线
- **云端备份**：支持 WebDAV / S3 等远程备份（可选，需你主动配置）
- **备份内容可控**：你可以选择备份哪些内容
- **签名校验**：正式版本强制签名校验，防止被篡改

## 开源透明

- **AGPL-3.0 许可证**：源代码完全开放，任何人可以审计
- **无闭源依赖**：移除了所有不可审计的闭源 SDK
- **Fork 可追溯**：基于 RikkaHub fork，上游同步记录完整公开

## 与云端 AI 应用的对比

| 特性 | Measix Pilot | 云端 AI 应用 |
|------|-------------|-------------|
| 密钥存储 | 你的手机本地 | 云端服务器 |
| 对话记录 | 你的手机本地 | 云端存储 |
| 账号要求 | 无需注册 | 必须注册 |
| 遥测上报 | 无 | 通常有 |
| 网络代理 | 直连 AI 服务商 | 经过中间服务器 |
| 数据删除 | 卸载即清除 | 需联系平台 |
| 源代码 | 完全开源 | 通常闭源 |
