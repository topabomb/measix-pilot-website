# 语音合成 — 让 AI 开口说话

> 让 AI 的回复从文字变成语音。Measix Pilot 支持多种语音引擎，中文朗读自然流畅，AI 多次语音按顺序播放，还能调节速度。

## 支持的语音引擎

| 引擎 | 说明 | 特点 |
|------|------|------|
| **系统 TTS** | Android 系统自带 | 免费，离线可用 |
| **OpenAI TTS** | OpenAI 语音合成 | 高质量，自然语音 |
| **MiMo TTS** | 小米 MiMo 语音 | 中文优化，支持音色设计 |

### 小米 MiMo 语音

- **标准模式**：预置多种音色（冰糖、茉莉等），可选风格
- **音色设计模式**：描述你想要的音色，AI 为你定制
- 根据模型自动切换配置界面

## 核心功能

### 🎵 顺序播放

同一轮对话中 AI 多次生成语音时：

- 首次语音打断之前的播放
- 后续语音追加到队列末尾**按顺序播放**
- 默认开启，可关闭恢复每次打断的行为

### ⚡ 播放速度

- 可调节播放速度：0.5x ～ 2.0x
- 默认 1.0x 正常速度
- 设置中提供滑块调节
- 自动应用到所有语音引擎

### 🗣️ 智能朗读

- 自动跳过括号内的内容（可配置）
- 智能过滤各种引号标记：直角引号「」、白直角引号『』、弯引号""
- 朗读范围：只读最后一条回复，或整个对话
- 可随时中断
- 生成后自动朗读（可配置）

### 🎯 语气引导

- 不同语音引擎可配置语气引导
- 让语音更有情感和风格
- 小米 MiMo 支持风格和音频标签引导

::: tip 朗读体验
Measix Pilot 的智能过滤让 AI 朗读更自然——不会读出 Markdown 标记、代码注释等无关内容，直接朗读有效文本。
:::
