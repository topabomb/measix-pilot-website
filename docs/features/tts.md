# 语音合成

> 让 AI 开口说话。Measix Pilot 支持多种 TTS（Text-to-Speech）引擎，让对话从文字扩展到语音。

## 支持的 TTS 引擎

| 引擎 | 说明 | 特性 |
|------|------|------|
| **System TTS** | Android 系统 TTS | 免费，离线可用 |
| **OpenAI TTS** | OpenAI 语音合成 | 高质量，自然语音 |
| **Gemini TTS** | Google Gemini 语音 | 多语言，情感丰富 |
| **MiMo TTS** | 小米 MiMo 语音 | 中文优化 |

## 核心功能

### 🗣️ 智能朗读

- 自动跳过括号内的内容（可配置）
- 引号过滤（支持直角引号「」和弯引号""）
- 语气标记引导，让语音更有情感

### ⚙️ 个性化配置

- **默认播放速度**：可调整 TTS 播放倍速
- **引擎选择**：每个助手可指定不同 TTS 引擎
- **触发方式**：手动朗读、自动朗读回复

### 🎯 朗读范围控制

- 只朗读最后一条 AI 回复
- 或朗读整个对话上下文
- 可随时中断朗读

::: tip 朗读体验
Measix Pilot 的 TTS 引号过滤和括号内容跳过功能，让 AI 朗读更自然——不会读出 Markdown 标记符号、代码注释等无关内容，直接朗读有效文本。
:::
