# AI 生图

> 用文字描绘，让 AI 为你创作图片。Measix Pilot 内置文生图功能，支持多种图像生成模型。

## 功能概述

Measix Pilot 集成了 AI 图像生成能力，你可以通过自然语言描述让 AI 生成图片：

- **文生图**：文字描述 → 生成图片
- **多模型支持**：根据 Provider 能力选择图像生成模型
- **尺寸选择**：支持多种输出尺寸

## 使用方式

1. 在对话中输入图像生成请求
2. AI 根据描述生成图片
3. 生成的图片直接显示在对话中
4. 可长按保存到本地相册

## 支持的生成参数

| 参数 | 说明 |
|------|------|
| **尺寸** | 支持多种分辨率选择 |
| **风格** | 通过文字描述控制 |
| **数量** | 可生成单张或多张 |

::: tip 提示词技巧
- 描述越具体，生成效果越好
- 可以指定风格（如"水彩画"、"油画"、"赛博朋克"）
- 可以指定构图（如"特写"、"全景"、"俯视"）
:::
