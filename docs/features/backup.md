# 备份与同步

> 你的对话数据，你做主。Measix Pilot 支持 WebDAV 和 S3 协议备份同步，让你的数据安全可控。

## 支持的备份方案

### ☁️ WebDAV

支持所有标准 WebDAV 服务器：

- 坚果云、Nextcloud、ownCloud 等
- 自建 WebDAV 服务器
- 支持基础认证和摘要认证

### 📦 S3 / COS

支持 S3 兼容协议：

- AWS S3
- 阿里云 OSS
- 腾讯云 COS
- MinIO 等自建对象存储

::: warning S3 下载修复
Measix Pilot 已修复 S3/COS 下载丢数据的问题，并完善了 COS endpoint 配置。请使用最新版本。
:::

## 同步功能

### 双向同步

- **上传**：本地数据备份到云端
- **下载**：从云端恢复数据到本地
- **双向同步**：自动检测变更，智能合并

### 文件夹同步

- 工作空间文件夹可单独同步
- 双向同步补录与孤儿清理
- 支持选择性同步

## 数据安全

- 所有传输通过 HTTPS 加密
- API Key 仅存储在本地设备
- 备份文件包含完整数据（消息、设置、助手配置等）
- 支持备份文件加密（取决于服务端配置）

## 恢复机制

- 备份后自动标记工作空间目录状态
- 恢复时检测目录缺失，标记 BROKEN 而非删除记录
- 支持一键清理聊天文件
- 工作区恢复备份后目录缺失会标记 BROKEN 状态

::: tip 备份建议
建议定期（每周）进行一次完整备份，并在更换设备前手动备份一次。这样即使设备丢失或损坏，你的对话历史和助手配置都能完整恢复。
:::
