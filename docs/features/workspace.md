# Linux 工作空间 — 口袋里的 AI 工作站

> 手机上运行完整的 Linux 环境，AI 可以执行命令、写代码、处理文件。这是 Measix Pilot 的杀手级功能——一台口袋里的 AI 工作站。

## 什么是工作空间

工作空间是一个运行在你 Android 手机上的隔离 Linux 环境。不需要 root，不需要刷机，AI 可以在里面：

- 执行 Shell 命令
- 读写文件
- 运行 Python、Node.js 等脚本
- 安装和管理软件包
- 操作你上传的文件
- 通过交互终端直接操作

## 核心特性

### 📁 文件管理

- 支持从文件管理器导入文件到工作空间
- 工作空间可作为文件管理器的保存目标
- 文件按类型分派打开方式：文本可编辑、图片可预览
- 一键清理：快速删除分类下的全部文件
- 支持图片格式：HEIC、HEIF、AVIF、ICO 等现代格式

### 🔧 智能目录

工作空间有几个智能目录，各有用途：

| 目录 | 用途 |
|------|------|
| **工作区** | AI 和你的主要工作目录，可读可写 |
| **上传区** | 你上传的文件，AI 只读（要改需先复制一份） |
| **临时区** | 临时操作目录，免审批，方便快速实验 |
| **技能区** | 跨工作区共享的技能文件 |

### 🛡️ 安全隔离

工作空间是一个隔离的 Linux 环境，不会影响你的 Android 系统：

- **文件隔离**：工作空间的文件系统与 Android 系统隔离
- **进程隔离**：退出时自动清理所有子进程
- **上传区只读**：你上传的文件 AI 不能直接修改，要改必须先复制
- **系统目录保护**：系统关键目录不允许 AI 直接访问
- **命令安全**：命令以安全方式传入，避免注入

### 📦 软件包管理

AI 可以在工作空间内安装软件包（如 `pip install`、`npm install`），为复杂任务提供运行时依赖。

## 典型应用场景

### 数据处理

```
用户: "帮我分析这个 CSV 文件，算出每月销售额"
  ↓
AI 把 CSV 导入工作空间
  ↓
AI 写 Python 脚本处理数据
  ↓
AI 生成可视化图表
  ↓
你获得分析结果
```

### 代码运行

```
用户: "写一段 Python 脚本抓取网页内容"
  ↓
AI 在工作空间创建脚本
  ↓
AI 执行脚本（需要你审批）
  ↓
AI 读取运行结果并回复你
```

### 文档处理

```
用户: "帮我把这个 PDF 的表格提取为 Excel"
  ↓
AI 导入 PDF 到工作空间
  ↓
AI 运行提取脚本
  ↓
AI 导出结果文件
```

::: tip 性能提示
工作空间在手机上运行，性能略低于原生 Linux。对于计算密集型任务，建议将耗时操作交给 AI 在服务器端完成，工作空间主要用于文件操作和轻量脚本执行。
:::
