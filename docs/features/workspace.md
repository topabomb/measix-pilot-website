# 工作空间沙箱

> 基于 PRoot 的完整 Linux 环境，让 AI 在移动设备上也能执行 Shell 命令、读写文件、运行脚本。这是 Measix Pilot 的杀手级功能——一台口袋里的 AI 工作站。

## 什么是工作空间

工作空间是一个基于 PRoot 的隔离 Linux 环境，运行在你的 Android 设备上。AI 可以在其中：

- 执行 Shell 命令（bash/sh）
- 读写文件
- 运行 Python、Node.js 等脚本
- 安装和管理软件包
- 操作上传的文件

## 核心特性

### 📁 文件管理

- 支持通过 SAF（Storage Access Framework）导入/导出文件
- 支持复制/移动文件到工作空间
- 文件管理器支持文本编辑与图片/视频预览
- 支持 HEIC/HEIF/AVIF/ICO 等现代图片格式

### 🔧 挂载与目录

- `upload` 目录：挂载用户上传的文件
- `/tmp` 目录：临时操作，可设为免审批
- bind mount 路径：支持读取挂载目录文件

### 🛡️ 安全边界

工作空间是隔离的 Linux 环境，不会影响你的 Android 系统：

- 文件系统隔离
- 进程隔离
- 网络访问受控

### 📦 软件包管理

AI 可以在沙箱内安装软件包（如 `pip install`、`npm install`），为复杂任务提供运行时依赖。

## 典型应用场景

### 数据处理

```
用户: "帮我分析这个 CSV 文件，算出每月销售额"
  ↓
AI 将 CSV 导入工作空间
  ↓
AI 写 Python 脚本处理数据
  ↓
AI 生成可视化图表
  ↓
用户获得分析结果
```

### 代码运行

```
用户: "写一段 Python 脚本抓取网页内容"
  ↓
AI 在工作空间创建脚本
  ↓
AI 执行脚本（需审批）
  ↓
AI 返回运行结果
```

### 文档处理

```
用户: "帮我把这个 PDF 的表格提取为 Excel"
  ↓
AI 导入 PDF 到工作空间
  ↓
AI 运行提取脚本
  ↓
AI 导出结果文件
```

::: tip 性能提示
工作空间基于 PRoot 运行，性能略低于原生 Linux。对于计算密集型任务，建议将耗时操作交给 AI 在服务器端完成，工作空间主要用于文件操作和轻量脚本执行。
:::
