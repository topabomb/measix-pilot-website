# 全文搜索

> 海量历史对话中快速定位你需要的信息。Measix Pilot 基于 FTS5 + jieba 中文分词，提供毫秒级的全文搜索能力。

## 技术架构

### FTS5（Full-Text Search 5）

基于 SQLite 的 FTS5 扩展，提供：

- 倒排索引
- 布尔查询
- 前缀匹配
- 排序权重

### jieba 中文分词

集成 jieba 中文分词库：

- 精确模式：最精确的中文分词
- 搜索引擎模式：对长词再次切分，提高召回率
- 自定义词典：支持添加专业术语

## 搜索能力

| 功能 | 说明 |
|------|------|
| **关键词搜索** | 支持中英文混合搜索 |
| **消息搜索** | 搜索所有对话中的消息 |
| **助手搜索** | 按助手名称或描述搜索 |
| **会话搜索** | 按会话标题或内容搜索 |
| **模糊匹配** | 支持拼音、近音词匹配 |

## 使用方式

1. 在聊天列表或设置中点击搜索图标
2. 输入关键词
3. 搜索结果按相关度排序
4. 点击结果跳转到对应消息

::: tip 搜索技巧
- 使用多个关键词用空格分隔表示「且」关系
- 搜索结果会高亮匹配的关键词
- 搜索历史会自动保存，方便重复搜索
:::
