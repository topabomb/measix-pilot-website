# 折叠屏 · 平板 · 手机全适配

> 无论手机、折叠屏还是平板，Measix Pilot 都能呈现最佳布局。铰链位置精确感知，半折放桌面时聊天在上半屏，矮横屏自动切紧凑输入。

## 自适应双栏布局

### 自动切换

屏幕足够宽时（展开折叠屏、平板竖屏），聊天界面自动变成「会话列表 + 聊天详情」双栏布局：

- 左侧会话列表，右侧聊天内容，一眼管理多个对话
- 普通手机和矮横屏保持单栏抽屉，不勉强双栏
- 设置、历史等页面维持全屏逐页导航，保持一致体验

### 折叠屏铰链适配

竖向折叠屏按**真实铰链位置**分区：

- 精确感知铰链位置，不靠屏幕比例猜
- 内容避开铰链区域，不会被折叠轴切割
- **桌面半折模式**（Tabletop）：聊天显示在**上半屏**，下半屏留给输入

### 弹层自适应

| 屏幕形态 | 弹出面板类型 |
|----------|-------------|
| 普通手机 | 底部弹层 |
| 宽屏 | 居中对话框 |
| 竖向铰链 | 限制在聊天详情侧 |
| 桌面半折 | 限制在上半屏 |

## 矮屏紧凑输入

聊天可用高度较低时（如矮横屏）：

- 自动切换**单行紧凑输入**模式
- 功能项保持完整，不因紧凑而丢失功能
- 最大化聊天区域可用空间

## 主题系统

基于 Material 3 设计系统，提供多种预设主题：

| 主题 | 风格 |
|------|------|
| **极简白** | 纯白底 + 中性灰 + 低饱和蓝 |
| **Claude** | 象牙白暖底 + 赤陶橙 |
| **AMOLED** | 纯黑底 + 高对比度 |

- 7 种自定义主题色板
- 深色模式跟随系统或手动切换
- AMOLED 模式下选中会话对比度增强
- 主题选择器四列网格布局

### 视觉细节

- 会话栏间距、标题层级、头像尺寸精心调校
- 工具授权操作视觉区分增强
- 粗体字重修复，OEM 字体下也能正确显示
- 附件菜单折行后与首行左对齐

## 沉浸式体验

- 助手详情页和设置页状态栏沉浸
- 内容可滚动到顶栏下方
- 键盘弹出时输入栏底部圆角贴合

## 导航

基于现代导航体系：

- 类型安全路由
- 深度链接支持（`measix://` 协议）
- 返回栈管理
- 模态弹层
- 全屏沉浸式聊天
