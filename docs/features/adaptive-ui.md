# 自适应 UI

> 无论手机、折叠屏还是平板，Measix Pilot 都能呈现最佳布局。基于 Material Expressive（M3）和 Navigation 3 的自适应界面。

## 全设备形态适配

### 📱 普通手机

- 标准单栏布局
- 紧凑的输入栏
- 底部导航

### 📐 折叠屏

- 展开后自动切换双栏布局
- 左侧对话列表，右侧聊天内容
- 折叠/展开平滑过渡动画

### 📲 矮横屏

- 紧凑输入栏适配
- 最大化聊天区域
- 优化键盘弹出时的布局

### 🖥️ 宽屏（平板）

- 弹层居中面板
- 多窗口分屏支持
- 鼠标和键盘优化

## Material Expressive 设计

基于最新的 Material 3（Material Expressive）设计系统：

- 动态色彩主题
- 表达式动画
- 自适应组件
- 无障碍支持

### 主题系统

- **极简白**：纯净的浅色主题
- **Claude**：温暖色调主题
- **网格布局**：有序的内容展示
- 自定义主题色（7 种预设）
- 深色模式自动跟随系统或手动切换

## 状态栏沉浸

- 助手详情/设置页状态栏沉浸
- 全屏沉浸式聊天体验
- IME 展开时隐藏输入栏底部圆角

## 导航体系

基于 Navigation 3 的现代导航：

- 类型安全路由
- 深度链接支持（`measix://` scheme）
- 返回栈管理
- 模态弹层
