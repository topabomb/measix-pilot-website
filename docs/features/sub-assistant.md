# 子助手 — AI 间的分工协作

> 一个助手不够用？Measix Pilot 支持主助手把子任务交给专门的子助手去完成，各自拥有独立的人设和工具权限，实现 AI 间的分工协作。

## 什么是子助手

子助手是 Measix Pilot 的一个特色功能。当主助手遇到不擅长的任务时，它可以把任务交给一个专门 configured 的子助手去完成。

举个例子：你在和「通用助手」聊天时让它翻译一段日文，通用助手可以自动把翻译任务交给「翻译助手」去完成，翻译助手用自己的专业人设和工具处理完后，把结果返回给通用助手，通用助手再综合回复你。

### 好处

- **专业分工**：每个子助手专注自己的领域，效果更好
- **上下文隔离**：子助手在独立会话中工作，不会干扰主对话
- **权限隔离**：每个子助手有独立的工具权限，更安全
- **模型灵活**：子助手可以用不同的 AI 模型

## 如何使用

### 创建子助手

1. 在助手设置中创建新助手
2. 填写能力描述（告诉主助手这个子助手擅长什么）
3. 开启「可作为子助手调用」
4. 配置该助手的人设、工具和模型
5. 设置是否对所有主助手可见，或只对指定助手可见

### 使用子助手

开启子助手功能后，主助手会自动根据任务选择合适的子助手。你也可以在对话中明确要求「让翻译助手来处理这段文字」。

::: tip 安全设计
创建子助手不需要审批，但修改和删除子助手需要你确认。主助手不能把任务交给子助手的子助手（禁止套娃），避免无限递归。
:::

## 典型场景

### 专业分工

为主助手配置多个专用子助手：

- **翻译助手**：精通多语言翻译，有自己的翻译风格
- **代码助手**：擅长编程和调试，有 Shell 执行权限
- **写作助手**：擅长创意写作和文案策划
- **分析助手**：擅长数据分析和可视化

### 上下文隔离

子助手在独立会话中工作，不会用自己内部的对话过程污染主对话。完成后只把结果返回给主助手，主助手综合后回复你。

### 权限隔离

每个子助手有独立的工具配置和权限。你可以创建一个只能读取文件、没有写入权限的子助手用于信息检索；再创建一个有完整 Shell 权限的子助手用于代码执行。各司其职，更安全。

## 可恢复执行

子助手的工作会自动保存。如果 App 中途被杀或手机重启，下次打开可以恢复之前未完成的子助手任务，不会丢失工作进度。
