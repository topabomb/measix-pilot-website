# MCP 协议集成

> MCP（Model Context Protocol）让 AI 不再是「只会说话」的助手，而是能真正「动手做事」的智能代理。Measix Pilot 是移动端少数原生集成 MCP 协议的客户端。

## 什么是 MCP

MCP 是一种开放协议，标准地让 AI 应用与外部工具服务器通信。通过 MCP，你可以：

- **连接工具服务器**：搜索、日历、文件管理、数据库访问等
- **OAuth 2.1 授权**：安全的授权流程，支持令牌自动刷新
- **DCR 动态注册**：无需预配置，动态发现并注册工具

## 支持的 MCP 能力

### 🔐 OAuth 2.1 授权

完整的 OAuth 2.1 授权流程支持：

- 授权码模式（Authorization Code Flow）
- 令牌自动刷新
- 安全的令牌存储
- 授权状态持久化

### 🔄 DCR 动态注册

支持 RFC 7591 定义的动态客户端注册：

- 无需预配置客户端凭证
- 动态发现并注册 MCP 服务
- 运行时获取访问令牌

### 🛠️ 工具发现与调用

- 自动发现 MCP 服务器提供的工具
- 工具列表实时同步
- 工具调用结果格式化展示

## 配置 MCP 服务器

1. 打开设置 → MCP 管理
2. 点击「添加 MCP 服务器」
3. 填入服务器 URL 或选择预设
4. 根据需要配置 OAuth 授权参数
5. 测试连接并保存

::: tip 内置工具
Measix Pilot 内置了多种本地工具（如日历查询、屏幕使用时间统计等），这些工具与 MCP 工具统一管理，AI 可以自动选择使用。
:::

## 安全保障

- 所有 MCP 连接均通过 HTTPS
- 工具调用支持 HITL 审批（详见[工具调用与审批](./tool-calling.md)）
- 请求头敏感值默认遮罩
- 连接参数变化自动检测
