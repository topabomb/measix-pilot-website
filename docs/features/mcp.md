# MCP 协议 — 让 AI 能动手做事

> MCP（Model Context Protocol）是一种开放协议，让 AI 不再只是「会说话」的助手，而是能真正「动手做事」的智能代理。Measix Pilot 是移动端少数原生支持 MCP 的客户端。

## MCP 能做什么

通过 MCP，你的 AI 助手可以连接外部工具服务：

- **搜索网页**：让 AI 实时搜索互联网信息
- **管理日历**：查询和创建日历事件
- **操作文件**：读写和管理外部文件
- **访问数据库**：查询和操作数据库
- **更多能力**：任何支持 MCP 协议的工具服务都能接入

## 核心能力

### 安全授权

- **OAuth 授权**：支持完整的 OAuth 2.1 授权流程，安全连接需要授权的工具服务
- **令牌自动刷新**：授权过期后自动续期，无需反复登录
- **一键撤销**：随时撤销授权，立即断开连接

### 稳定连接

移动端网络环境复杂多变，Measix Pilot 针对性地做了深度优化：

- **冷启动恢复**：打开 App 自动检查并恢复所有 MCP 连接
- **网络切换恢复**：WiFi 和蜂窝网络切换后自动重连
- **智能省电**：网络离线时不消耗电量尝试连接，网络恢复后自动接回
- **休眠机制**：长时间连不上时进入休眠，不持续耗电
- **状态清晰**：每个 MCP 服务器都有明确的状态图标和文案

### 工具发现

- **自动发现**：连接 MCP 服务器后自动获取它提供的工具列表
- **实时同步**：服务器端工具变更时自动更新
- **结构化结果**：工具返回结果格式化展示，清晰易读

### 服务器分享

- **二维码分享**：把 MCP 服务器配置生成二维码，一扫即导入
- **文本分享**：支持通过文本分享配置
- **一键导入**：扫二维码或粘贴文本即可添加

## 如何配置

1. 打开设置 → MCP 管理
2. 点击「添加 MCP 服务器」
3. 填入服务器地址，或扫描二维码导入
4. 根据需要配置 OAuth 授权
5. 配置请求头（密钥默认遮罩保护）
6. 连接成功后即可使用

::: tip 密钥保护
MCP 服务器的请求头密钥默认按密码方式遮罩显示，需要手动点击才临时可见。这样即使截屏分享也不会泄露密钥。
:::

## 安全保障

- 所有 MCP 连接均通过 HTTPS 加密
- 工具调用支持人工审批（详见[工具调用与审批](./tool-calling.md)）
- 请求头密钥默认遮罩
- 正式版本强制签名校验
