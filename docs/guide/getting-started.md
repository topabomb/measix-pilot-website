# 快速开始

> 五分钟上手 Measix Pilot，开启你的移动 AI 之旅。

## 第一步：安装

1. 从 [GitHub Releases](https://github.com/topabomb/rikkahub_mcp/releases) 下载最新版 APK
2. 允许「安装未知来源应用」
3. 安装并打开应用

## 第二步：配置 Provider

首次启动时，所有预设 Provider 均为**禁用状态**，需要手动启用并配置 API Key。

1. 打开设置 → Provider 管理
2. 选择你要使用的 Provider（如 OpenAI）
3. 启用该 Provider
4. 填入 API Key
5. （可选）配置自定义 Base URL
6. 返回主界面

::: warning 安全提示
API Key 仅存储在本地设备中，不会上传到任何服务器。请确保设备安全。
:::

## 第三步：创建助手

1. 点击助手管理
2. 创建新助手
3. 填写助手名称
4. 选择模型
5. （可选）配置系统提示词
6. 保存

## 第四步：开始对话

1. 返回主界面
2. 点击右下角新建对话
3. 选择助手
4. 在输入框输入消息
5. 发送，等待 AI 回复

## 第五步：探索进阶功能

- **工具调用**：开启 MCP 工具，让 AI 执行实际任务
- **工作空间**：让 AI 在沙箱中运行脚本
- **消息分支**：重新生成，探索不同回复路径
- **全文搜索**：搜索历史对话内容
- **备份同步**：配置 WebDAV / S3 备份

## 常见问题

### 应用崩溃？

确保你的 Android 版本 ≥ 8.0（API 26），且设备有足够内存。

### 无法连接 API？

检查 API Key 是否正确，网络是否畅通。如果你使用自定义 Base URL，确保 URL 格式正确。

### 模型不支持？

不同模型支持不同功能（如多模态、工具调用）。请确认你选择的模型支持所需功能。
