# MCP 工具配置

> MCP（Model Context Protocol）让 AI 连接外部工具服务器。本指南介绍如何配置 MCP 服务器。

## 添加 MCP 服务器

1. 打开设置 → MCP 管理
2. 点击「添加 MCP 服务器」
3. 填入服务器 URL
4. 根据需要配置 OAuth 授权参数
5. 测试连接
6. 保存

## OAuth 2.1 授权

对于需要授权的 MCP 服务器：

1. 添加服务器后，点击「授权」
2. 系统会打开浏览器进行 OAuth 授权
3. 授权成功后，令牌会自动存储并刷新
4. 授权状态持久化，无需重复授权

::: tip DCR 动态注册
支持 DCR（Dynamic Client Registration）的服务器，无需预配置客户端凭证，Measix Pilot 会自动完成动态注册。
:::

## 内置工具

Measix Pilot 还内置了多种本地工具：

| 工具 | 说明 |
|------|------|
| 日历查询 | 查询今日/本周事件 |
| 日历创建 | 创建日历事件 |
| 屏幕使用时间 | 统计 App 使用时长 |
| 文件操作 | 工作空间文件读写 |
| 终端 | 工作空间命令执行 |

内置工具与 MCP 工具统一管理，AI 会根据需要自动选择。

## 工具审批

在工具管理页面，你可以为每个工具设置审批级别：

- **自动允许**：无需确认直接执行
- **需审批**：需用户确认后执行
- **禁止**：不使用此工具

详见 [工具调用与审批](../features/tool-calling.md)。
