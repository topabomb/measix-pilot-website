# 工作空间使用

> 工作空间是 Measix Pilot 的核心进阶功能，提供基于 PRoot 的 Linux 沙箱环境。

## 初始化工作空间

1. 打开设置 → 工作空间
2. 首次使用需要初始化（下载 rootfs）
3. 等待初始化完成
4. 工作空间就绪

## 导入文件

### 通过 SAF 导入

1. 在工作空间页面点击「导入」
2. 选择文件（支持多选）
3. 文件会复制到 `upload` 目录
4. 支持复制/移动到其他目录

### 支持的格式

- 图片：JPG、PNG、GIF、WebP、HEIC、HEIF、AVIF、ICO
- 文档：PDF、DOCX
- 代码：各种文本格式
- 数据：CSV、JSON、XML 等

## 文件管理

- 支持文本编辑
- 图片/视频预览
- 目录浏览
- 复制/移动/删除

## 让 AI 使用工作空间

在对话中，AI 可以：

- 执行 Shell 命令
- 读写文件
- 运行脚本（Python、Node.js 等）
- 安装软件包

::: warning 审批
涉及写入操作的命令需要审批。你可以将 `/tmp` 目录设为免审批，方便快速实验。
:::

## 备份与恢复

- 工作空间可单独备份
- 恢复后检测目录状态
- 目录缺失标记 BROKEN 而非删除记录
- 支持文件夹同步（双向）
